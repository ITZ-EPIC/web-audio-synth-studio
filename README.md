# ⚡ PulseWave — Web Audio Synth & Visualizer Studio

PulseWave is an interactive, browser-based synthesizer with an auto-arpeggiator and a real-time frequency visualizer. It is built as a single-file project with vanilla HTML, CSS, JavaScript, and the Web Audio API.

## Features

- **Four oscillator sounds:** Sawtooth lead, triangle pluck, square-wave chiptune, and sine sub-bass.
- **Eight playable notes:** C4, D4, E4, G4, A4, C5, D5, and E5.
- **Keyboard controls:** Play notes with `1`–`4` and `Q`, `W`, `E`, `R`.
- **Auto-arpeggiator:** Start and stop a repeating sequence across all eight notes.
- **Live spectrum display:** Visualize audio frequencies with the Web Audio API `AnalyserNode` and canvas.
- **No dependencies:** Open `index.html` in a modern browser; audio starts after the first interaction.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Click a pad or press one of the listed keys to start audio.
4. Choose an oscillator sound or start the auto-arpeggiator.
